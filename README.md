# To-Do List

To-Do List application to demonstrate Ruby on Rails Knowledge

## Description
To-Do list consisting of tasks items. Each item will have a title, description, status, and timestamps. Actions include creating, updating, reordering, and deleting tasks.

## Installation
* git clone https://github.com/eyergens/to-do.git
* cd to-do
* rbenv install 3.2.0
* rbenv local 3.2.0
* bundle install
* yarn install
* rails db:create
* rails db:migrate
* rails db:seed
* bin/dev

## Dependancies
Built with Ruby v3.4.2 and Rails v8.0.2.1 on MacOS
